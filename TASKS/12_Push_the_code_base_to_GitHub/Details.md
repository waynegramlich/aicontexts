# 12 Push the code base to GitHub

Push the `aicontexts` code base up to GitHub as the public repository
`waynegramlich/aicontexts`, doing as much as possible with the `gh`
command and using the GitHub web site only as an absolute last resort.

* Create the repository first; it is pushed only once the `ISSUES/`
  list is empty.
* Follow `R.gsr` (GitHub Setup Rules) and `R.gar` (GitHub Actions
  Rules), and update both rules (in `rule_sources/`) with whatever is
  learned along the way.
