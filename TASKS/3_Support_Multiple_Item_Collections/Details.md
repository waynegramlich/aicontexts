# 3 Support Multiple Item Collections

Each class of Item (e.g. issues, tasks) is an independent collection that
lives in its own directory (e.g. `ISSUES/`, `TASKS/`).

Decided so far:
* There is still only one `TASKS/Startup.md`.  It lists the `@` imports
  for the Items of every collection (e.g. `@../ISSUES/...`).
